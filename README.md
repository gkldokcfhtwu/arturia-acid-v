## Overview

Arturia Acid V is a meticulous emulation of the Roland TB-303 acid bass synthesizer, preserving the iconic squelchy filter and sequencer behavior while adding modern features for contemporary acid music.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Acid V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **303 Filter** | Diode ladder filter with accent and slide behavior as in the original |
| **Step Sequencer** | Classic 303-style step sequencer with accent, slide, and tie per step |
| **Distortion** | Built-in overdrive and distortion for modern acid textures |
| **Extended Range** | Additional waveforms and filter modes beyond the original hardware |
